how the loop closes

five stages. one gate that matters.

most fine-tuning pipelines fail on data quality: they train on whatever the agent happened to do. foundry trains only on what the agent proved — the same witness-test contract stella already enforces on every task.

stage/01 · capture

capture the work

every production task stella runs — the plan, each tool call, each diff, the outcome — is recorded as a deterministic, replayable trajectory. it never leaves your boundary.

mechanism → staged pipeline journal + deterministic replay; zero telemetry egress by default
stage/02 · verify

prove it, or drop it

an independent verifier authors a witness test that fails on the old code and passes on the new. only trajectories with a clean fail→pass flip — and no tampering — become training signal. everything else is discarded.

mechanism → witness stage, flip oracle, tamper exclusion, verifier ≠ worker
stage/03 · distill

distill into open weights

verified trajectories and frontier-teacher traces fine-tune an open-weight base model — llama-, qwen-, or mistral-class — on your infrastructure. the checkpoint is yours, not an api you rent.

mechanism → supervised fine-tuning + preference passes over verified pairs, in-vpc training
stage/04 · evaluate

gate on parity

each candidate replays golden task suites head-to-head against the frontier baseline. it ships only inside the parity threshold; a regression never deploys.

mechanism → golden replay fixtures, side-by-side flip scoring, cost-per-solved-task ledger
stage/05 · deploy

route, then repeat

the router sends matched work to your tuned model and escalates the hard tail to frontier. every routed task re-enters capture — so next cycle's model is trained on this cycle's proofs.

mechanism → confidence-based routing, canary rollout, frontier fallback — the loop closes

built for the enterprise boundary

what large customers actually get to keep.

your vpc, your data

capture, training, evals, and serving all run inside your boundary. zero telemetry egress by default — the same contract stella ships with today.

weights you own

the deliverable is an open-weight checkpoint you hold and can serve anywhere — not access to someone else's endpoint that can be repriced or retired.

auditable lineage

every training example traces back to a deterministic replay and its witness proof. when a regulator asks what the model learned from, there's an answer.

frontier as the safety net

the router escalates low-confidence work to the frontier model, so accuracy never dips below baseline while the loop keeps tightening the gap.
