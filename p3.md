## The gap

`PIPELINE_SYSTEM_PROMPT` carries scope-of-engineering discipline ("MINIMAL FIX… No refactoring. No 'while I'm here' edits", ≤3 files), but the default interactive persona (`SYSTEM_PROMPT`, `prompt.rs:110`) has only "Make minimal, surgical edits. Use edit_file, not write_file" — which is about *edit mechanics*, not about how much engineering the task deserves. Nothing in the default persona discourages unrequested refactors, speculative error handling, premature abstractions, or gold-plating; and nothing addresses failure persistence — when an approach fails, diagnose before switching, don't retry identically, don't abandon a viable approach after one failure.

## What the comparator carries

Zappy's "Doing tasks" cluster is its best-earned content (it reads like distilled eval findings):
- "Don't add features, refactor code, or make 'improvements' beyond what was asked. A bug fix doesn't need surrounding code cleaned up."
- "Don't add error handling, fallbacks, or validation for scenarios that can't happen. Trust internal code and framework guarantees. Only validate at system boundaries."
- "Three similar lines of code is better than a premature abstraction… no speculative abstractions, but no half-finished implementations either."
- "If an approach fails, diagnose why before switching tactics — read the error, check your assumptions… Don't retry the identical action blindly, but don't abandon a viable approach after a single failure. Escalate only when genuinely stuck, not as a first response to friction."

## How to port it

A shared `complexity_discipline!` contract embedded in BOTH personas (the pipeline's MINIMAL FIX step then becomes a specialization, not the only carrier), written in Stella's argued style — each rule with the failure it prevents — plus a parity row and per-clause pins. The diagnose-before-switching clause complements the existing loop-detection machinery from the prompt side: the engine detects identical-call loops after the fact (`driver/loop_escalation.rs`); the contract reduces how often they form.
