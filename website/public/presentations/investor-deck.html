the invention

The witness protocol.

Oxagen replaced the judge with an oracle. A task is done only when a unit test proves it: a test that fails on the old code and passes on the new. Not an opinion. A flip.

A deterministic system controls the definition of done. Models do the work. They never grade it.

how it works

The oracle flip.

1An independent verifier authors a witness test in a shadow sandbox.
A separate model, in a detached workspace. The worker never touches it, and the working tree is never mutated.
2The test runs on the old code. must fail
Proof the behavior was genuinely absent before the change.
3The test runs on the new code. must pass
Proof the behavior is genuinely present after it.
4Tamper evidence voids the flip.
If the worker modified the witness files, the proof is invalidated. No credit.

fail → pass, witnessed, tamper-checked. Beyond problematic, probabilistic LLM judges.
