the origin

I built stella with AI — and it lied to me.

It began as a thesis test, not a company: whatever can be handled deterministically should be, by a tool with a strict IO contract — the model asked only for what no tool can do. The motive was economics, so the core shipped with no IO and protocol-driven wire contracts.

1The thesis held.Deterministic tools took the deterministic work. Token spend fell; capability did not.
2Then it claimed work it had not done."Complete," it said — test never run, file never saved. Routinely, and confidently.
3So "done" stopped being an opinion.Nothing closes until an independent oracle flips a test from fail to pass on real evidence.
4Then the side effect nobody planned.Every verified run is a trace pre-labeled with its outcome — agent training's scarcest asset.

The verification we built to stop being lied to turned out to be a data factory. That is the platform.

the trap

You're paying to train the lab you depend on.

The most valuable thing your team makes with a coding tool is not the code. It is the traces: every step, every fix, every decision. Today they vanish into someone else's model.

Your traces are the asset. And you're giving them away.

stella captures and verifies those traces, so the hardest part of training your own model is already done.

the invention

The witness protocol.

Oxagen replaced the judge with an oracle. A task is done only when a witness test proves it — failing on the old code, passing on the new. Not an opinion. A flip.

1An independent verifier authors the witness in a shadow sandbox.A separate model, in a detached workspace, after reading the executed diff. The worker never touches it, and the working tree is never mutated.
2The test runs on the old code. must failProof the behavior was genuinely absent before the change.
3The test runs on the new code. must passProof the behavior is genuinely present after it.
4Tamper evidence voids the flip.If the worker modified the witness files, the proof is invalidated — no credit. The flip is additional evidence, never a substitute: the project's own suite still gates the change.

A deterministic system controls the definition of done. Models do the work — they never grade it. Failure modes, named and guarded: appendix A2.

the byproduct

Verified work labels itself.

Every flip yields a training example with ground truth attached: the goal, the context, the diff, and a deterministic proof that it worked. No human labelers. No judge models. The label is the flip.

appendix · A2 · for technical diligence

What the flip does not prove.

A protocol with no named failure modes is an unexamined protocol. These are ours — with the guards that ship today, and the gaps that do not.

1A flip can be shallow.A weak witness proves something changed, not that the right thing was delivered. Guards: the witness is authored by an independent verifier model after reading the executed diff — never by the worker — and tampering voids credit. Roadmap: mutation-scored witness quality, adversarial witness review.
2A flip is silent about regressions.It proves the named behavior arrived, not that nothing else broke. Guard: the project's own test suite still gates the change; the flip is additional evidence, never a substitute.
3Not all work has an oracle.UI, refactors, performance, migrations and design have no clean fail → pass test. We have published no measured oracle-able share of enterprise work — we measure it per pilot. Guard: non-oracle work runs under the warrant system, typed pre-action justification instead of a flip. The corpus bias toward testable work is real; the curriculum weights against it.
4Flips are optimizable.A model trained on flips could learn to produce trivially-flippable work. Guards: the witness is written against the executed diff by a model with no stake in the reward; the worker never sees it in advance; voided flips are excluded from training; and the ladder abstains rather than credit an unprovable claim — an abstention is never training data.

The oracle-coverage percentage is deliberately unnumbered: no measured figure exists yet, and this deck does not carry a number without a measurement behind it.

your traces
